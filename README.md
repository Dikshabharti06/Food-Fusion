# Food Fusion 🍔

Food Fusion is a full stack food ordering web application developed to provide users with a seamless and interactive online food ordering experience. The platform allows users to browse food items, explore menus, and place orders through a responsive and user-friendly interface.

## 🚀 Features
- User-friendly food ordering interface
- Browse and explore food menus
- Add to cart functionality
- Responsive frontend design
- Dynamic food item display
- Backend integration for data handling

## 🛠 Tech Stack
### Frontend
- HTML
- CSS
- JavaScript
- React.js

### Backend
- Node.js
- Express.js

### Database
- MongoDB
